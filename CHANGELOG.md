# Changelog

## v0.5 — tap-only controls + unified tree

- Удалены отдельные кнопки запуска и флипперов: управление идёт только через тап/удержание игрового поля.
- Удалена пользовательская пауза.
- Прогресс поля встроен в верхний HUD; HUD больше не перекрывает игровую геометрию.
- Автоотбив убран с игрового экрана и из экрана автоматики; переключатель находится только в Настройках.
- Нижняя навигация также имеет зарезервированную область, поэтому флипперы всегда видимы.
- Апгрейды модулей обновляют DOM точечно, без пересоздания мастерской или карточки деталей.
- Древо навыков объединено в одну горизонтально прокручиваемую карту из четырёх ветвей.
- Выбор и покупка ранга навыка обновляют существующее дерево на месте и сохраняют положение скролла.
- Обновлены smoke/layout тесты и мобильная камера.

## v0.4 — fixed-width live table

- Флипперы гарантированно видны.
- Стол ограничен шириной 430 px.
- Меню и мастерская работают как живые оверлеи.
