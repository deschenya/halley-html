# Kaskad Pinball v0.14

Мобильный HTML-прототип incremental pinball. Игра автономная: `index.html` не требует сервера, CDN или внешних ассетов.

## Запуск

Откройте `index.html` в современном браузере. Для разработки можно запустить `python serve.py` и открыть локальный адрес.

## Управление

- Нет шарика: удерживайте игровое поле и отпустите, чтобы запустить шар.
- Шарик в игре: тап по полю активирует флипперы.
- Короткий тап по модулю улучшает его, если хватает монет; при нехватке используется прототипная мгновенная реклама.
- Удержание модуля открывает карточку с описанием и заменой.
- Если шар вернулся в стартовый канал, он паркуется на пружине. Это не проигрыш. Удержание поля повторно запускает тот же шар и сохраняет текущий забег.

## Прогрессия полей

- Цель первого поля: 2 000 очков; далее цель растет примерно в 1.72 раза.
- На новом поле очки поля сбрасываются до 0.
- Уровни всех установленных модулей и встроенных прокачиваемых элементов сбрасываются до базового уровня 1.
- Типы купленных модулей, их размещение, монеты, кристаллы и дерево навыков сохраняются.
- Навык C6 применяется уже после сброса и дает стартовый бонус уровня двум установленным модулям.
- Постоянное усиление между полями сосредоточено в дереве навыков.

## Ранние поля

- Поля 1–2: 4 симметричных сокета.
- Поля 3–4: 6 симметричных сокетов.
- С поля 5: 8 базовых сокетов, далее расширения открываются прогрессией и навыками.
- Стартовая сборка — четыре круглых бампера. Палочка не доступна до поля 5.
- На полях 1–4 нет дополнительных встроенных устройств.
- С поля 5 встроенные устройства появляются зеркальными парами.
- Опасности появляются только на поздних полях и также размещаются симметрично.

## Визуальная обратная связь

- Светлые яркие игровые палитры и синий базовый шар.
- Комбо отображается только как `×N` на светлой плашке.
- На максимальном текущем комбо под плашкой появляется огонь; шар получает огненный трейл и огненное свечение.
- Иконки монет, гемов и настроек — единые векторные SVG.

## Структура

- `index.html` — готовая автономная игра.
- `template.html` — HTML-шаблон сборки.
- `src/game.js` — модель, физика, UI и Canvas-рендер.
- `src/style.css` — интерфейс и анимации.
- `build.py` — собирает `index.html`.
- `tests/` — проверки механики и мобильной верстки.
- `docs/` — исходный дизайн-документ.

## Ограничения прототипа

Сохранение локальное (`localStorage`). Реклама имитируется мгновенной выдачей недостающей валюты. Сетевой сервер, платежи, реальные рекламные SDK и лидерборды не подключены.
