# Каскад v0.5

Мобильный автономный HTML-прототип пинбол-инкременталки. Внешние библиотеки, CDN, шрифты и сетевые запросы не нужны.

## Запуск

Открой `index.html` в современном браузере. Локальный сервер не требуется.

## Управление

- Если шарика нет: зажми игровое поле и отпусти — пружина запустит шарик.
- Пока шарик на поле: любой тап по самому столу синхронно дёргает обе ручки.
- Отдельных кнопок запуска, флипперов и паузы нет.
- Автоматические ручки включены по умолчанию; переключатель находится только в `Меню → Настройки`.
- Магазин, навыки, карта, настройки и мастерская открываются поверх работающей игры и не останавливают физику.

## Экран и камера

- Верхний HUD занимает отдельную безопасную полосу и не перекрывает пинбол.
- В HUD встроены поле, очки/цель, полоска прогресса, монеты и кристаллы.
- Игровой стол занимает всё оставшееся пространство между HUD и нижней навигацией.
- Ширина стола не растягивается дальше 430 px.
- Масштаб X зависит только от ширины; по Y поле адаптируется к высоте устройства.
- Флипперы и слив всегда остаются видимыми.

Проверенные viewport: 320x568, 360x640, 360x740, 390x844, 430x932 и 1440x900.

## Мета и интерфейс

- 8 типов модулей, покупка, склад, расстановка, повороты и уровни.
- Апгрейд модуля обновляет только его карточку/детали, цену и HUD — модальное окно не пересоздаётся.
- Древо из 28 навыков показано единой горизонтально прокручиваемой картой из четырёх направлений.
- Выбор и покупка навыка обновляют дерево на месте без перезагрузки экрана.
- 30 полей, дальнейшая экспедиция, автоматика, офлайн, оболочки, мастерство, схемы и песочница.
- Экспорт/импорт сохранения через JSON.

## Структура

- `index.html` — готовая автономная игра.
- `template.html` — шаблон standalone-сборки.
- `styles.css` — интерфейс и мобильная адаптация.
- `src/model.js` — данные, экономика и метапрогресс.
- `src/engine.js` — физика и игровые механики.
- `src/render.js` — Canvas-рендер и камера.
- `src/mobile.js` — мобильные меню.
- `src/app.js` — приложение, сохранения, редактор и UI-логика.
- `build.py` — пересборка `index.html`.
- `tests/` — механические, браузерные и layout-тесты.
- `docs/` — исходный GDD.

## Пересборка

```bash
python build.py
```

Прогресс хранится в `localStorage`. Песочница использует отдельный профиль.
