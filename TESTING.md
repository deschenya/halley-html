# Testing v0.12

Команды запускаются из корня проекта.

```bash
node tests/v012_requirements.cjs
node tests/v012_launch_30.cjs
python tests/ui_v012.py
python tests/v012_spring_ui.py
```

Проверяется:

- цели и упрощенная прогрессия сокетов ранних полей;
- круглая стартовая сборка и блокировка палочки до поля 5;
- зеркальная геометрия и отсутствие пересечений на 30 полях;
- сброс уровней модулей и встроенных элементов при смене поля;
- парковка вернувшегося шара на пружине без события проигрыша;
- повторный ручной запуск припаркованного шара с сохранением забега;
- 630 комбинаций `30 полей × 21 сила запуска`;
- мобильная компоновка, индикатор силы запуска, квадратные SVG-иконки и UI-анимации;
- отсутствие необработанных ошибок в Chromium.

Актуальный результат сборки: требования 79/79, запуск 630/630, UI 83/83, парковка пружины 3/3.
