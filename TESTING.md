# Проверка Каскада v0.5

## Smoke test

```bash
python tests/smoke_test.py
```

Проверяет: управление только через поле, отсутствие кнопок запуска/паузы, HUD без перекрытия поля, видимость флипперов, live-overlay меню, автоотбив только в Настройках, точечный апгрейд модулей и единое горизонтальное дерево с обновлением на месте.

## Тесты механик

```bash
node tests/engine.test.cjs
```

Проверяются экономика, комбо, cooldown, устройства, мультибол, офлайн-расчёт, сохранения и автоматика.

## Тесты мобильной компоновки

```bash
python tests/layout_test.py
```

Viewport: 320x568, 360x640, 360x740, 390x844, 430x932, 1440x900. Проверяется отсутствие overflow, независимая ширина стола, адаптация только по высоте, отдельная зона HUD, видимость флипперов и горизонтальный скролл единого дерева.
